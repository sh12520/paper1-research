# RDINP 研究目标与阶段门禁

2026-11-28。面向 6G 智能体网络，研究不可靠链路与共享边缘算力下的限时意图协商和服务履约。先推进小论文目标（GOAL-1），验收后由作者确认是否进入硕士论文扩展（GOAL-2）。

## GOAL-1　验证限时履约问题并形成小论文

在强单边基线已经具备幂等任务身份、重新准入、持久化结果重查、有限租约、唯一代际、执行点期限守卫、因果幂等取消、安全释槽和固定本地回退时，验证提交状态分歧或回退信息迟滞是否仍会造成可复现的业务损失。只有度量到可归因的残差，才设计使用双方合法可观测信息、可实际执行的恢复机制。目标是一篇可复现的通信或系统类小论文。

| 阶段 | 研究内容 | 验收依据 |
| --- | --- | --- |
| G1-A　并发判定 | 4 终端／1 槽及 8 终端／2 槽，标称负载 0.4／0.7／0.9，按相同释放计划与分向故障窗配对 | 对照纯本地 B0、增强单边 B1、瞬时回退信息 B2-info。独立模型 B2-ideal 只作零停止尾段的敏感性分析。以全部释放任务计分，主要指标为合格结果按期采用率。 |
| G1-B　机制与完整对照 | 在人工确认 Go 后，对已复现的失败提出因果可执行的处理，沿用 B1 与相同任务及质量规则 | 核对额外消息改变了哪项执行决策，报告采用、回退、资源与安全结果。若 B2-info 有可复现的正向差距，估算机制回收的比例。拟在 Ubuntu 端点验证 `tc netem`，单列 5G-LENA 前传轨迹敏感性和 Caddy 副作用观察。 |
| G1-C　边界与交付 | 整理条件安全性、时限界、配对数据和复现材料 | 列出时钟、链路及执行尾段前提，以实际结果采用区分控制承诺和履约。提交小论文初稿及可追溯证据。 |

### 当前判定

G1-A 已完成 144 个同机配对，共 5,184 条任务×方法记录。96 个中高负载配对中，B2-info 相对 B1 的合格按期采用率差为 −0.174 个百分点，95% CI [−0.434, 0.000] 个百分点。两种实测边缘方法均未观测到槽位不足导致的准入拒绝，预期的后继任务争用链尚未覆盖。判定为 `INCONCLUSIVE_REQUIRES_MANUAL_REVIEW`，GOAL-1 正在等待人工决定。 [判定报告](../../rdinp/experiments/durable-worker/G1A_DECISION_REPORT.md)

- **Go 证据。** 按冻结判定协议，核对中高负载下可归因的改善。原工程参照为主指标至少提高 5 个百分点且区间支持，或出现显著且可归因的后继任务被拒或超期损失。公开回退时刻、准入不对称或自然完成可解释的样本不能构成新增信息见证。
- **Pivot 证据。** 只有在实际故障、回退和共享槽位争用均有覆盖的情况下，小效应与缺少可归因的后继损失才能支持结束当前夹具的占槽假设。可能的后续验证是旧执行者副作用与新任务期限冲突，或真实业务中强因果降档后的残差。两者优先检验强基线是否已足够。
- **本轮审阅问题。** 请判断应补测真实共享槽位争用、收窄到更具体的履约问题，还是先补目标业务和 SLA。专家建议供作者作 Go/Pivot 决策。[冻结判定协议](../../rdinp/experiments/durable-worker/G1A_DECISION_PROTOCOL.md) · [审阅提示词](../EXTERNAL_RESEARCH_EXPERT_PROMPT.md)

## GOAL-2　硕士论文扩展

GOAL-1 形成可投稿初稿及冻结复现实验包后，由作者明确确认切换。硕士论文扩展包括三个相互连接的部分。

1. 完善算力与频谱约束消息、Schema、签名覆盖及可执行许可。先通过真实边缘槽位验证履约链，频谱执行接口与动态发现依据可用资源另行扩展。
2. 整合小论文机制、条件证明和并发对照，说明状态查询、代际保护、按期采用、回退以及实际安全释槽的关系。
3. 验证独立端点与时钟误差，接入一个能够取得真实业务约束和同任务事件轨迹的边缘载荷。OPV2V 保留为候选载荷与强单边参考，CS-ODS 保留为历史方法资产。

本机 Windows 用于轻量回归、证据复核和撰写。已配置的 Ubuntu 用于并发 CPU 试验和获准的链路注入。实际业务 SLA、时钟界和执行尾段上界以各试验的证据为准。 [开题报告评审版](RDINP_硕士学位论文开题报告_评审版.md) · [当前推进](../current-research.md)
