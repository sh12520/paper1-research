## 目前证据

**现行问题。** 多终端共用波动无线链路与有限边缘槽位。慢环依据已观测的链路与队列，协商主档、轻量边缘档和本地兜底。快环在已承诺的范围内切档或回退，采用结果仍检查任务身份、回执、期限和代际。作者已封存原单机 G1-A 取消诊断。请把 SQLite 释槽、HTTP CANCEL 和 Caddy 排空留作历史边界。本轮优先判断无线和算力波动下的多档履约。

**开发仿真。** r02 比较固定意图、被动重协商、静态回退与结构化 RDINP，共 81 个配置 × 10 个种子，每种方法 75,330 个已释放任务。r02 修正了队首等待高估。终端用回执携带的队列快照，被动重协商可复用已上传主档输入。三个带本地兜底的策略都按期交付。结构化方案相对加强后的被动重协商平均效用 +0.0078，每任务少 0.52 轮、16.1 ms 和 108 控制字节。相对静态回退效用 +0.0116，每任务多约 520 控制字节和 13.7 ms。参考工况在 600 和 800 ms 下，静态回退效用点估计略高。

**机制归因。** 保持菜单、消息大小、任务、链路和兜底一致，只开关承诺后的快切，平均效用 +0.0119，探索性配对 95% 区间 [0.0106, 0.0132]，边缘交付率 +10.05 个百分点。按 400、600、800 ms 分层的效用差依次为 +0.0228、+0.0068、+0.0061。质量以三张样图与主档边缘图的相似度计分。5G-LENA 前传容量回放的平均忙时低于 0.55%，压力主要来自受控空口扰动和共享边缘队列。

**原型成本。** 开发仿真以两次抽象往返记账。历史签名 C2 四阶段成功路径的应用层 JSON 消息体共 9,734 字节，138 个相关控制链的实际耗时中位数 2.73 秒。按同一模型换成四阶段消息大小，在 400 ms 截止且预留 55 ms 本地时间、空口速率持续降半、无排队和重传时，上传前选轻量档余量中位数 +74.8 ms，主档上传后再切为 +9.1 ms。理想预算、历史软件实测和未来原型时延是三个口径。
