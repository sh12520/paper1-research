# 其他电脑的研究方向

每个新方向在同一个私有仓库中使用一个 `research/<方向短名>/` 目录和对应的 Git 分支。按该方向已有的工作流组织。入口以简短的 README 为主，下面的文件名可按实际内容调整。

- `README.md` 说明问题、当前结果和运行入口。
- `CURRENT.md` 和 `EVIDENCE.md` 记录阶段、假设、研究判断和可追溯的正负证据。
- `REFERENCES.md` 优先复用[共享书目](../literature/README.md)的键和 DOI。
- `autoresearch/` 或现有工作流目录保留可共享的提示词、实验脚本、评估条件和小型复现。旁支线索可单独留存。
- `NAVIGATION_REVIEW.md` 记录从全局入口实际完成的查找，包括跳转断点和补充建议。

已有路线见[全局目录](../docs/research-index.md)。自主整理、上传与验收见[第二台电脑的 Codex 提示词](../docs/SECOND_COMPUTER_AGENT_PROMPT.md)。
