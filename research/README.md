# 其他电脑的研究方向

每个新方向在同一个私有仓库中使用一个 `research/<方向短名>/` 目录和对应的 Git 分支。已有的 RDINP、CS-ODS 和不可变历史档案继续可以从[全局目录](../docs/research-index.md)访问。

- `README.md` 说明问题、当前结果和运行入口。
- `CURRENT.md` 记录状态、约束和下一项决定性验证。
- `EVIDENCE.md` 链接报告、汇总数据以及必要的单案证据。
- `REFERENCES.md` 优先复用[共享书目](../literature/README.md)的键和 DOI。
- `NAVIGATION_REVIEW.md` 记录从全局入口实际完成的查找，包括跳转断点和补充建议。

整理、上传与验收步骤见[第二台电脑的 Codex 提示词](../docs/SECOND_COMPUTER_AGENT_PROMPT.md)。
