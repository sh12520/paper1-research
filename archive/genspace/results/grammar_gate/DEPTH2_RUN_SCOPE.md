# Depth≤2 comparison scope

The online manifest binds the fixed original seed-index-0 instance in each of the 96 configurations plus 32 existing high-cost comparison instances. The latter are the first eight qualifying original plan slots outside the fixed set in each of F1–F4. Qualification uses the archived development audit's target membership and conditioned candidate count ≥100,000. The selection file contains IDs only. The public cursor receives neither the cohort label nor the reference outcomes.

The frozen engineering caps per cursor are 12 seconds, 300,000 expanded partial nodes, 180,000 queued search nodes and 768 MiB sampled worker working set. A capped prefix remains a valid certificate only for the contracts already emitted. Top-K and protocol paths have independent cursors. K=500 is the cost gate, consistent with `INDEX-GATE-01`. G4 requires p95 at most twice the archived contract-aware index and at most 70% of the FLAT p95 on the same high-cost cohort, using the preceding 30% engineering improvement criterion to operationalize the requested comparison against FLAT.

If the fixed batch cannot complete the mandatory correctness comparisons within its limits, exhaustive target coverage has not been demonstrated practical under this implementation. A capped query's consumed time or score count is a lower bound on the work to certify K=500. The report may use only such lower bounds, and zero lower bounds for unobserved cases, to show an already-certain full-cohort quantile failure. It keeps this mathematical bound separate from descriptive statistics for measured or completed queries. The depth3 gate requires all depth≤2 gates to pass.

The source and serialized instances remained identical.
