# Semantic equivalence in the finite benchmark

This is a proof for the current abstract Python benchmark and one fixed, well-formed `PublicInstance`; it is not a theorem about real networks. A well-formed public instance has unique state/time capacity cells, the serialized typed registry and model parameters accepted by the interpreter. Admissible `PrivatePreferences` have finite weights in the documented positive sampling ranges and finite reservations in [0,1]. An all-zero weight vector does not define the utility formula and is not an admissible preference.

Let `N` be the recursive normalization in `src/state_machine.py`: each `If(moving,A,B)` whose children have equal public semantic signatures becomes the lexically smaller normalized child before V2 and execution; children normalize first and recursive comparisons strictly descend in AST size. Unknown condition names are never removed. This definition treats deployment/setup as cost zero and deliberately does not model a separate deployed observer for this redundant expression. Let `sig(x)` be `semantic_key(x, public)`. A signature contains (1) the normalized whole-contract capability footprint: each role name, its public input/output types, predicate names and their evaluated truth values, effects, registry costs, supported scopes and required scopes; (2) the V3 semantic-validity bit; and (3) for valid behavior, every ordered `(time,state)` cell as idle, or `(quality,deadline,rate,offload, active role set, runtime costs)`. Missing role declarations and V3-invalid behavior have explicit sentinels. It uses neither private preferences nor provider IDs. Roles are semantic operation names, not provider identities. Setup cost is zero. The key itself does not claim that policies are V1 legal: the lemma conditions on both passing the same configured V1/depth check.

**Lemma.** Fix an admissible public instance and a depth bound D. For any two ASTs x and y that both pass V1 at D, `sig(x) == sig(y)` implies the same V2 result, the same V3 result and guarded behavior, the same V4 result, and identical V5 application utility, network utility and acceptance outcome for every admissible private preference record, whenever those later stages are reached. If an earlier stage rejects, the subsequent stages are not evaluated. 

**V2.** Equal footprints have identical role names, serialized role descriptors, required scopes and truth values for every declared predicate. The public available provider IDs and registry are fixed. Binding in `bind_capabilities` compares descriptor signatures, not provider IDs; hence each requested role has a match for x exactly when it does for y. Interpreter compatibility, supported-scope checks and the closed public predicate checks therefore yield the same pass/fail result. Normalization is performed before obtaining the footprint. Unknown predicates fail closed. Duplicate descriptor-equivalent provider IDs do not alter existence.

**V3.** The same V3 validity bit gives equal semantic rejection for invalid trees. In this case no compiled guarded behavior exists. If valid, the equal cells explicitly specify the same active/idle state, quality, deadline, rate and offload at every public time and exogenous state. These are exactly the selections made by the interpreter's local-time `If`, `Sequence`, `Delay`, `ValidFor` and `Offload` semantics. Consequently the guarded behavior is identical.

**V4.** Given an active cell, the same profile/offload and fixed public model give the same base demand. Equal active-role sets and the same fixed registry give the same role resource surcharges and execution costs. Each cell starts from the same public capacity, so the reserve transitions and per-cell feasibility decisions coincide. Idle cells have identical no-op transitions and zero runtime charges. The public hard constraints operate on the equal ordered action schedule and hence also agree. Capability declaration and precondition checks happen earlier in V2.

**V5.** The application formula uses only this guarded action schedule and fixed public horizon/states. The network formula uses those same actions, the per-cell resource surcharges, execution costs, and public demand model. Since each of these inputs is equal, substituting any one admissible private weight/reservation record yields identical utilities, clamping and reservation comparisons. There is no private input to `semantic_key`, `normalize`, capability binding, V1–V4, or candidate generation.

The role set per active cell is retained even if two different sets currently sum to the same numeric cost. This is necessary for sound composition: a parent can add a role already present in only one child and the per-cell charging rule uses set union. A whole-contract footprint is retained separately because V2 checks declared roles and scopes even when some branch never executes. A bare service schedule or aggregated numeric costs would not establish this lemma. This is a sufficient operational signature, not a claim that every observationally indistinguishable tree is merged. Exact enumeration and bottom-up context congruence additionally require separate reference-comparison tests; the lemma alone proves neither.
