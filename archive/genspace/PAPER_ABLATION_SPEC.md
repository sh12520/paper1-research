# PAPER-BASELINE-ABLATION-01 · 单因素消融规范

六条消融以同一个惰性 `DepthCursor` 为对照，用于 depth≤2 和 depth≤3。能力、有限公开 grammar、合法深度、规范键、原 FLAT binary64 分数、稳定并列规则、验证器和双边协议均保持一致。depth≤2 保留旧 FLAT 的一至两组结构合同，depth≤3 保留一至四组结构合同。B2 静态候选由同一协议独立处理。 [实现](results/paper_method_dev/ablations.py) · [对照游标](results/depth3/depth_search.py)

**A2 和强通用基线使用不同的抽象界。** A2 在原搜索中只保留独立坐标区间界。主比较中的 `GENERIC_ABSTRACT_BEST_FIRST` 还对每个有限输出因子做局部联合最小化，区分 idle 与 active 的角色成本，然后与坐标区间界取较强值。A2 的结果解释原游标内部的下界切换，强通用基线比较归于另一条实证比较。 [通用基线及区间界](results/paper_method_dev/generic_search.py)

**A4 保留原 transfer 并支付其计算成本。** A4 的唯一改变是将 transfer 得到的包络在传给相同评分界之前跨单元拓宽。它检验原有状态／时间／资源信息对界和搜索的贡献。实际 wall time 还包含额外并集代价，无法估计改用从零构建的廉价抽象域的成本。

## 切换内容

| 消融 | 唯一切换与安全条件 | 对应工作量与预计影响 |
|---|---|---|
| A1 `NO_EARLY_SEMANTIC_DEDUP` | 保留已经计算的规范符号模板，将同一模板的不同来源各自推入赋值队列。在完成赋值时按原语义键做唯一性检查，汇合该键的待选 witness。所有同分 frontier 块排除后，才输出原词典序最小代表。 | 看 `merged_template_states`、`terminal_duplicates`、展开节点、完成赋值次数、witness recipe 数、运行时和峰值内存。重复来源增加待展开工作。推迟归并会增加 frontier，也可能减少某些归并索引成本。 |
| A2 `GENERIC_BOUND_ONLY` | 在原先相同的精细包络上使用通用坐标区间界；分别计算 violation、margin、quality、cost 和机制组下限所需端点，保留精确叶端评分。合同专用的单元内联合下界被移除。 | 对照 `lower_bound_evaluations`、骨架与赋值展开数、精确评分次数、待处理峰值和运行时。单次界更轻，证书前需检查的状态可能更多。 |
| A3 `DEFER_CAPABILITY_PRUNING` | 用相同 typed 参数域展开骨架和 profile 赋值，能力 availability 的拒绝延后到完整赋值形成时。由原始算子角色决定资格。不可用来源的相等模板单独归并，继续推入赋值队列，在精确评分前拒绝成品，避免条件折叠后混入合法候选的词典序代表。 | 看 `deferred_capability_rejects`、骨架生成与展开、符号 partition probes、墙时和峰值。预期影响集中在 sparse 夹具。rich 夹具没有缺能力时，通用启动及判定成本仍须单列。 |
| A4 `WEAK_STATE_TIME_RESOURCE_ENVELOPE` | 保留合同专用下界算法和原合法性排除，但对六个单元的公开候选做并集，将同一个 sound 备选摘要传入全部单元。每个实际单元的 profile、idle 及资源选择仍被覆盖；mandatory roles 取交，possible roles 取并。全合同最小机制组数保持原值。 | 比较 bound calls、展开数、评分数、frontier、wall 和 RSS。精细 transfer 仍用于计算合法性与来源信息，该消融测量向评分界提供时空精度的价值。区间并集的成本计入本臂耗时，不能据此估算删除全部语义 transfer 的速度。 |
| A5 `NO_LAZY_STOP` | 使用同一个游标。对同一查询保存首次取得所需精确前缀的时点与证书；消融策略继续处理完整有限域才完成交付。证书逻辑、合法集合和顺序不变。达到安全限额时记录未完成交付以及此前的已认证检查点。 | 比较首次认证后的额外展开、完整候选、精确评分、墙时和峰值。全域无需预建图。资源截尾只给额外全域成本的下界。 |
| A6 `NO_SEARCH_TIME_DOMAIN_NORMALIZATION` | 以原始算子骨架及全体 profile 位置的等值划分为赋值模板，跳过搜索期按观测位置消元和规范语义模板。Partial 评分使用原 transfer 计算各 slot 的安全备选集；即使某 slot 是单点，也以 profile hole 参与抽象计算，保留条件可能折叠的 sound 分支。所有 slot 赋完值后才生成原始 AST，并按原规范键归并、确定精确分数和最小 witness。 | 看 raw templates、partition probes、raw ASTs、终端重复、待处理峰值和时间。早期键仍可合并完全相同的 raw 模板。因为规范表示被推迟，不能再在这一步合并不同 raw 形状的已规范等价类。这是规范化与 A1 的内在交互，比较仅回答当前配置下的边际作用。 |

## 同域保证与各切换的正确性依据

设 `R(q,d)` 为查询的公开能力所允许的原始 typed 合同语法树，`σ(r)` 为原合同解释器的规范键。结构域由所有 `r∈R(q,d)` 的 `σ(r)` 唯一化并按对应深度的原结构组范围筛选。每条臂输出同一个 `(score(σ(r)), σ(r))` 全序，并为每个键保留最小的合格原始序列化。验证和接受按原协议触发。

1. **A1 保持语义键商集。** 若原模板等价类在符号层具有来源集合 `T`，原游标将来源作为一个赋值流的多条 recipe。A1 让每个来源单独经过同一赋值规则，到完成后才做相同键的集合并。并合集合不随归并层级改变。对每个终端键取所有来源及其隐藏变量最小补全中的最小 raw witness，得到相同代表。
2. **A2 保持每个开放节点的下界。** 容量分母按原定义为正。每个资源需求的下端点给出非负超载项的下界，以及截断 margin 的上界。profile quality 用上端点，角色成本和最小机制组数用下端点。分数分别沿这些方向单调，且累加、除法和评分保持原 binary64 顺序。用相同顺序替换这些端点仍给出每个完成式的下界，叶端精确 score 保持一致。移除较强联合界会放宽状态与截止点的竞争范围。 [原评分界](GRAMMAR_BOUND_SPEC.md)
3. **A3 延后过滤等价于先过滤。** 将候选骨架扩为相同参数域的所有 typed 产生式。先按原始骨架是否可用把模板的 recipe 存在独立命名空间；叶端完成赋值后应用恒等的公开角色谓词 `required(raw) ⊆ available_roles`。谓词与 profile 赋值无关。对合法候选可交换赋值与角色过滤，保留原合格集合与代表。独立命名空间防止某个非法原始来源在规范键相等时改变代表。
4. **A4 保守地拓宽各单元。** 若 `E[j]` 是原第 j 个单元的区间及离散候选摘要，统一的 `join(E[0],…,E[5])` 覆盖每个 `E[j]`。profile 掩码和 idle 取并，mandatory roles 取交，possible roles 取并。该变化同时放宽单调区间端点和单元内联合最小化的备选集合。保留合法性筛选与全合同最小机制组数，同一 score 函数及舍入余量因此仍给出合法下界。
5. **A5 策略只改变交付时点。** 首次精确停点前逐步使用完全相同的游标、键和剪枝。之后每次成功发射都晚于已认证前缀，因而继续到穷尽不会改变已获得的排序结果。首次证书与穷尽交付各自有状态和计量，后续资源截尾不使已经验证的前缀失效。
6. **A6 推迟规范化保持分割的完备性。** 每个全量 profile 笛卡尔赋值按各原始位置取值相等关系唯一落在一个等值划分内。从该划分及块间 all-different 的 profile 赋值可重建原树。搜索用带剩余值域的 typed holes 作为保守抽象，允许忽略跨块相关性，并保留所有潜在条件折叠。完整赋值后才按原 `σ` 计算合法性、原 FLAT score 和代表。该开关同时减少可利用的早期已规范等价，故 A6 的边际结果包含规范化与归并的交互。

对所有开关，只有完整候选的分数严格低于每个开放状态的下界，或已排除所有开放状态，才能发射。此测试还保护任何同分且语义键更小的候选，以及同一键尚未处理的、更小 raw witness。A1/A6 对追加到已发出键的来源直接报错。证明范围是当前有限语法、公开基准转移和已有的离散域假设。实际运行通过独立缩减域穷举检查完整集合和 witness，并在固定开发查询上比较已认证前缀。资源限制下未访问的后缀保持未知。

## 比较与解释

对每条臂使用同一输入和预算。原始 AST materialization、符号完成赋值尝试、已评分不同语义类、已发出规范 witness AST、局部并集次数和协议验证次数分别记录。A1 共享终端精确评分以避免在确认键相同后重复打分，故该臂的成本差主要体现在重复赋值和 frontier。A6 按真实发生的原始 AST 解码和后续规范 witness 重建分别计数。对限制内无法完成的臂保留终止原因、可认证前缀及未完成的后续工作，不能将早停成本填为完成成本。

- **完整配对的边际差。** 只在双方达到同一 K 的精确认证目标时，统计消融减去当前方法的 wall time 和工作量差。穷尽短域属于精确目标；应附绝对差、配对分母及配置组成。相对百分比仅在分母正且非空时计算。
- **全体已尝试查询的限额惩罚。** 以同一深度的 wall cap 为未能交付的运行计入一个固定惩罚，已交付使用实际耗时；同时报告认证／交付覆盖、各资源停止原因和成对结果。这个指标度量固定预算策略，无法恢复未完成运行的真实完成时间或工作量。若双方的 p95 都落在惩罚点，还需查看认证覆盖及更低 K 的配对结果。
- **截尾工作量。** 对因时间、RSS、前沿或展开限额中断的查询，已记工作量描述停点。方法若沿同一轨迹继续，后续完成需要至少这些工作。把它与完整配对差分混报可能低估消融成本。对 A5 另在消融自身的同次运行计算「穷尽或停止时」减「首次证书」的额外步数和耗时。穷尽的增量为实测值，受限增量为下界。
