# Public abstract semantics for partial contracts

The graph-free cursor represents a partial contract as the existing DSL constructors with typed `ClauseHole` or `ProfileHole` leaves. A clause hole carries the maximum remaining operator depth and a shared immutable public grammar domain. The domain records the 27 scalar profiles, permitted operator parameters, and available canonical roles resolved from the public registry. A profile hole has depth zero. `AbstractSemantics.expand` fills just the first unresolved hole in preorder. Each child of a binary production has an independent occurrence of the hole even when the immutable descriptors compare equal. The search can therefore cover all publicly generated syntactic derivations without requiring a list of a hole's complete descendants.

The implementation is in `results/grammar_gate/abstract_semantics.py`. Its public semantics are those of `src/state_machine.py`, especially `normalize`, `_active_roles`, and `semantic_key`. Its demand extrema use the original `results/method_dev_v1/public_search.py::_proxy` base-demand formula. Physical surcharges, hard constraints, and bilateral preferences remain the responsibility of the downstream verifier and protocol.

## Meaning of an envelope

Each of the six `(time, state)` cells records a possible idle flag and two finite sets of profile IDs, one each for local and edge service. The sets are represented as bitmasks. A cell may be active when one of its profile sets is non-empty and must be active when idle is impossible. Demand, quality, deadline, and rate extrema are the extrema over those possibilities, with a zero contribution for idle. Offload state comes from the two profile sets and the idle flag. Cell runtime roles have a mandatory bitmask contained in the role set of every concrete outcome and a possible bitmask containing each such role set. A possible idle cell has an empty unconditional mandatory runtime-role set.

A separate contract-wide footprint encloses the roles declared by the whole normalized AST, including wrappers and children that never execute in a given cell. The minimum mechanism-group count is the number of FLAT groups intersecting the mandatory contract-wide footprint. A second count uses the possible footprint for an upper bound. These four groups follow `public_search.group_bits`, including the common phased/validity group. The score proxy's quality upper bound is the cell-ordered sum of cell quality maxima divided by six. The cost lower bound uses zero for potentially idle cells and the minimum exact proxy cost over every superset of a must-active cell's mandatory role mask otherwise. The superset minimum over the fixed role lattice gives a bound even if a monotonicity assumption about addition were inappropriate. Its size is fixed by the 12 public roles, independent of grammar depth or utterances. The cell-ordered cost lower bounds are summed and divided by six. The exact score includes its original weights, operations, and tie-breaking rules.

For each allowed remaining depth, the homogeneous clause-hole envelope is computed by one abstract recurrence from the previous depth. The recurrence joins the `Static` summary with every available constructor/parameter applied to the previous summaries. A join takes the union of profile options, possibility of idle, and possible roles and the intersection of mandatory roles. It makes no Cartesian product over child completions. The only persistent reusable items besides the public domain are finite profile/role tables and bounded caches of encountered cells and partial subtrees. No availability table built from complete semantic classes enters this recurrence.

## Transfer soundness

Induct on the partial tree and, at a clause hole, on remaining depth. The following transfers enclose the normalized semantics of every legal completion whenever each child summary encloses its completions. Independent per-cell unions allow combinations that may not be jointly achievable, which yields a conservative envelope.

| Constructor | Construction and reason for inclusion |
|---|---|
| `Static` | In each cell the fixed profile, or every profile allowed by the profile hole, is active in local mode. Its runtime and whole-contract roles are the five base roles. This contains every scalar choice and is exact once the hole is filled. |
| `If` | In a retained conditional, each `moving` cell reads the left branch at its original time and each `still` cell reads the right branch. Conditional roles are unioned into active cell roles and the whole footprint includes both children. Normalization may erase `If('moving', ...)` when complete branch keys are equal. The collapse branch intersects the child profile/level alternatives and intersects possible roles while unioning mandatory roles, under the assumption of equality. A shared idle cell is retained where both sides permit it. Disjoint envelopes rule out equality. When equality is undecided, the result joins retained and collapse possibilities, so it cannot incorrectly force or charge conditional roles. With two complete children, the existing compact encoder decides any remaining ambiguity. Equal hole descriptors alone never imply equal concrete branches. |
| `Sequence` | Before the duration, the cell reads the first child at time `t`. After that prefix it reads the second at `t-duration`, keeping the same state. An active cell additionally requires the phasing role. Both subtree footprints contribute to the contract-wide role mask. These are precisely the dispatch and role additions of `_active_roles`. |
| `Delay` | Cells before the offset are idle. Later cells read the same state at `t-offset` and add the scheduling role if active. Declared roles remain in the whole-contract footprint even when a cell is idle. |
| `ValidFor` | Outside its half-open interval the result is idle. Inside it, each cell reads the same state at `t-start` and adds the validity role if active. The whole footprint includes the validity role and the child's footprint. |
| `Offload` | Time and state are unchanged. Each active cell promotes every allowed local/edge profile option to edge mode and adds the two offload roles. A child idle alternative stays idle. Set union charges a role once per active cell, including through nested wrappers. |

Each constructor is selected from the existing fixed public parameter domain and only receives child holes of smaller remaining depth. Each production matches the publicly available constructor roles in `src/engine.py::enumerate_compositions`. Allowing unavailable conditional syntax solely to collapse an equal branch cannot add a new normalized signature, since that same branch is separately reachable within a smaller depth. Complete candidates use compact public signatures for semantic deduplication and the exact verifier later decides actual public and bilateral feasibility. Capacity, utility, reservations, hidden preferences, and historical success values do not influence grammar expansion or the abstract transfers.
