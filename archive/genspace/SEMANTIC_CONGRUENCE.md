# Context congruence of the benchmark signature

This analysis concerns the current abstract interpreter, a fixed well-formed public instance, and V1-typed ASTs. It does not concern deployed networks. For equal semantic signatures, we examine substitution into the same constructor context and whether a V3-invalid child can become valid. No study outcomes are used.

## Prior counterexample and repair

The original syntax-only normalization was not a congruence. For static P, let `a = Delay(1, Offload(edge, P))` and `b = Offload(edge, Delay(1, P))`. Their signatures are equal, but the old rule removed `If(moving, a, a)` and retained `If(moving, a, b)`, producing different signatures. An independent reduced-domain search found another example involving nested Sequence trees.

The current public-only normalization first normalizes children and collapses `If(moving, A, B)` whenever their complete public semantic signatures agree, choosing the lexically smaller normalized child. Each recursive comparison descends to smaller trees. Unknown conditions are not erased. This makes the reported counterexample pass and models zero setup cost for this redundant condition; it does not claim a deployed observer is free.

## Constructor argument

For a valid child, its signature records active or idle behavior, profile, offload, active role identities and runtime costs for every local time and exogenous state. A parent only selects, rebases, crops, or modifies these recorded cells. Roles are combined by set union; retaining identities matters because equal numeric costs alone are insufficient under a parent union. The whole normalized capability footprint separately records role descriptors, required scopes and closed public predicate outcomes. Under the current predicates, wrapping a child adds fixed role and scope requirements and combines local predicate checks conjunctively. Base-operation scope sets are transformed consistently when embedded. Equal signatures therefore provide the same inputs to these constructor operations.

For an IF, the collapse decision itself depends on equality of child signatures. Substituting a child with another of the same signature preserves that decision; when collapsed, both possible normalized witnesses have that signature. Unknown conditions remain explicit. This supports the one-hole congruence argument under the current closed predicate vocabulary and operational model; changing either requires reassessment. It does not prove that different signatures are distinguishable, or that a reported lexical witness is globally minimal.

V3-invalidity is monotone under constructors: the semantic checker recursively requires all children to be valid, even in unselected branches. If an IF collapses, the chosen child has the same signature and validity bit as its sibling, so an invalid child is not silently repaired. Invalid signatures carry the false validity bit and public V2 footprint rather than a compiled schedule. This statement is conditional on the current normalization and recursive checker.

## Independent reduced-domain check

For one profile, one value for each structural parameter, two states and three time slots, all 91 depth-at-most-two ASTs formed 47 signature classes. All 99 equal-signature pairs were placed into both positions of IF and Sequence with all 91 AST anchors, plus each unary constructor: all 36,333 comparisons passed, in 100.77 seconds. This is engineering evidence for this reduced domain, not full 27-profile depth-two completeness. Automated tests also cover the repaired counterexample and invalid profile, timing, condition and offload children in constructor contexts. Full streaming-reference equality remains a separate gate.

## Constructor-specific obligations

The following arguments assume both child trees have already passed V1 and have the same current `semantic_key` on the same public instance. Equal keys include the same whole-tree roles, their declared descriptors, required scopes, each declared predicate's truth value, and the V3 validity bit. They also include every guarded cell when V3 is valid. This is outcome equivalence for a **single fixed public instance**; it is not equality across two public registries or a theorem about a different implementation.

- **Delay(o, A).** At local time `t < o` the cell is idle. At `t >= o` it queries A at `t-o`, adds the scheduling role to its active role set, and retains A's profile and offload. Equal full-horizon child cells give equal queried cells, and inactive cells incur no runtime role cost. The scheduling role and the public test `0 < o < horizon` are the same for both parents. A nonpositive or too-large offset makes the parent invalid; adding another constructor cannot make it valid.
- **ValidFor((l,r), A).** The parent is idle outside the half-open interval and queries A at `t-l` inside. It adds the validity role to an active path. The parent-specific predicate checks the same endpoints, and semantic validity requires `0 <= l < r <= horizon`. Reversed or out-of-range endpoints are invalid regardless of the child.
- **Offload(level, A).** Each active child cell gets the supported level and the offload plus edge-reservation roles; idle stays idle. A repeated role is counted once by active-role set union. The same level gives the same public predicate result and surcharge. Unknown levels fail the supported-level checks. The current domain has only `edge`; any extension to several levels requires revisiting the nested-offload behavior and this argument.
- **Sequence(d, A, Z)** and **Sequence(d, Z, A).** Before `d`, the first child sees `t`; afterward the second sees `t-d`. The phasing role is added to the selected active path. Equal A cells and the common Z cells therefore give equal parent cells in either position; all values queried are within the recorded horizon for a valid duration. The predicate and V3 checks both require `0 < d < horizon`, and recursively check both children even if one would not be observed in a particular cell.
- **If(moving, A, Z)** and **If(moving, Z, A).** After recursive normalization, the parent first compares the *complete* public child signatures. Replacement of A by an equal-key child preserves whether the two branches compare equal. If equal, the parent collapses to one equal-key witness before V2; if unequal, it retains the conditional and observation roles and selects the same state-indexed branch in each cell. Required roles/scopes and predicate outcomes are preserved under the same union. `If(unknown, ...)` is not collapsed; its predicate and V3 validity are false, including when its children agree.

For every constructor, a child's top-level `static` scope marker is replaced by the enclosing scope when it is embedded; already nested static operations collect the enclosing scope as a set. Structural-role scopes are collected by union. Since both the role set and each role's required scope set are in the key, and the current predicate vocabulary checks whole-tree values by conjunction, equal child keys give equal parent V2 inputs. If a required role is missing from the available provider IDs, both parents lack a matching binding; if the role is present but its declared supported scopes do not include a required scope, both fail V2; and if a public predicate is false, both fail V2. For a serialized declaration incompatible with the interpreter's fixed capability vocabulary, both fail V2. These statements assume a well-formed registry record that `registry_from_public` can deserialize; malformed dictionaries can raise before any V2 outcome and are outside the lemma.

Arbitrary V1-typed AST parameters need not belong to the frozen finite grammar: for example a known string field can contain an unknown condition, an integer duration can be negative, and a finite profile can lie outside the public scalar domain. The signature records the relevant public predicate outcomes and a false V3 bit where applicable. It does not fabricate a schedule for a V3-invalid tree. Equality of two such invalid keys concerns their earlier V2 outcome and shared V3 rejection only; V4 and V5 are not reached. Cases that fail V1, malformed public state, exceptions from arbitrary user-supplied functions, nonfinite weights and zero-denominator preferences are outside this benchmark theorem.

## What this does and does not establish for DP

One-hole substitution congruence supplies an induction ingredient: if a depth-`d-1` class has a representative of depth at most `d-1`, applying each finite-domain constructor to representatives covers the signature obtained from any depth-`d` syntax tree. The induction additionally needs a separate check that a V3-invalid child cannot become V3-valid after wrapping, and that normalization, parameter-domain restrictions, public capability filtering, and representative selection are exactly the same in both implementations. In particular, a lexically smaller representative can be deeper than another member, so the implementation must retain an eligible shallow witness for further composition. Global lexical minimality is a separate property.

This document gives the operational argument and reduced-domain tests; it does **not** certify that the current compact transfer implementation, cached semantic library, or full-domain streaming reference satisfy all of those obligations. Those are implementation-level claims requiring exact independent equality checks under the current source/config fingerprint. The independent 27-profile depth-two reference comparison was subsequently completed and matched every compact key byte for byte; see `EXTERNAL_REFERENCE_AUDIT.md`. The compact implementation remains restricted to its stated public grammar and the engineering timing gate remains unmet; no smoke run is authorized.

## V2 outcome equivalence versus failure monotonicity

These are different statements. **Outcome equivalence** says that two equal-signature children put into the same context have equal V2 outcomes. **Failure monotonicity** asks whether a particular child that fails V2 must still fail V2 after it is wrapped. The former alone does not imply the latter.

For the current fixed interpreter vocabulary and default role descriptors, failure remains a V2 failure under a V1-admissible parent context in the following cases. A required unavailable semantic role remains in the normalized parent footprint. IF normalization can remove one of two branches only when their signatures, including their role and predicate footprints, are equal, so it cannot remove the last occurrence of the missing requirement. A false current closed predicate remains false: each value-dependent predicate is a conjunction over the relevant normalized nodes, and equal-signature replacement preserves the recorded predicate outcome. A changed or unknown serialized predicate declaration fails the earlier interpreter-descriptor compatibility check, and its required role remains present. The same applies to an incompatible serialized scope declaration. If a wrapping tree exceeds the configured depth, the observed first failure is V1 instead; it is not a successful V2 repair.

The **unsupported-scope** case needs a narrower claim. In the current reference registry, static operations support every scope the current grammar assigns to them, including both `static` and `delayed`; structural roles support the scope their node assigns. A serialized registry that removes one of those scopes no longer equals the interpreter's fixed role descriptor and therefore fails compatibility even if wrapping changes the requested scope. Thus an unsupported scope cannot be used as an independent compatible-registry repair in the current interpreter.

It is **false** that unsupported-scope failure is monotone for arbitrary future interpreters. The regression `test_alternate_interpreter_can_repair_unsupported_static_scope` explicitly patches the interpreter and matching serialized registry so `set_quality` supports `delayed` but not `static`. Under that alternate vocabulary, `Static(P)` fails V2 for unsupported `static` scope, while `Delay(1, Static(P))` passes V2: embedding replaces the static scope marker with `delayed`. This is a concrete counterexample to a universal scope-monotonicity theorem; it does not alter the production vocabulary. A DP that prunes all V2-invalid children therefore needs the current-vocabulary assumptions, or must preserve potential scope repairs. Reduced constructor tests cover missing offload, false profile membership, disabled reservation, incompatible scope and unknown-predicate declarations; they are checks, not exhaustive enumeration of every public instance.

**Scoped pruning conclusion:** under the current fixed reference registry and closed predicate vocabulary, a well-formed fixed public instance, the current semantic-aware normalization, and parent ASTs admitted by V1, the argument above permits pruning a child whose first failure is V2 without losing a parent that would pass V2. This conclusion does not extend to arbitrary patched interpreter vocabularies, and it does not replace independent DP/reference equality tests. The regression exhaustively applies the finite list of eight unary/binary constructor contexts to each of five representative V2 failures (40 combinations), plus the alternate-interpreter counterexample; it is not an exhaustive sweep of all ASTs or public instances.

An additional reduced-domain engineering enumeration is recorded in `results/engineering/invalid_exhaustive_report.json`. It enumerated all 140 distinct V1-typed children of depth at most one in its explicitly specified domain (including invalid profiles, conditions, durations, offsets, intervals and offload levels), four anchors, all 20 legal parent constructor placements in that domain, and six public capability/constraint settings. Among these, 824 child-scenario cases failed V2 and 744 had false V3 validity. There were 16,480 V2-parent checks and 14,880 V3-parent checks, with zero unexpected repairs and zero exceptions. The separately patched alternate interpreter again repaired unsupported static scope (V2 to V5). The helper and source/config hashes are recorded with the result. This is an exhaustive check only of that reduced domain, not all ASTs, registries or public instances.
