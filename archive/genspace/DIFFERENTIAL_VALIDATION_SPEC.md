# Exact evaluator differential protocol — draft fixed before comparison

This is an engineering-only protocol. It creates no smoke, pilot or confirmation instances or outcomes. It does not authorize any study run. The candidate universe is the complete, untruncated graph of 1,394,064 compact signatures; evaluation and comparison never use private utility or reservation to generate candidates or to prune candidates before V5. Each of the four family fixtures must use the ENGINEERING namespace and one serialized instance shared by both paths.

For every graph record, in the same class-ID order, compare public eligibility, V2/V3-equivalent admissibility, V4 physical/hard feasibility, both utilities, acceptance, Nash product, semantic novelty relative to the exact public B2 signature set and behavior-based mechanism labels. Stages that cannot be reached because an earlier stage failed must have the same explicit not-applicable marker on both paths. The V2/V3 distinction and any public early-filter reason must remain observable; a combined filter is not enough to claim an independently checked stage split. For both paths independently select the maximum utility product and use the exact canonical lexical witness tie-break; compare the selected class and reconstructed representative exactly. The same equal candidate set, not merely agreement yes/no, is required.

The numerical comparison rule is fixed before the full comparison: finite `u_application`, `u_network`, and Nash values are compared with absolute difference at most **1e-12**, no relative tolerance. NaN or infinity is always a mismatch. If the paths use the same scalar operations in the same order, additionally record bitwise equality. Boolean capacity decisions, acceptance decisions, class IDs, public filtering, stage reachability, semantic novelty, labels, canonical witness and final selected class must agree **exactly**, including values close to a capacity or reservation boundary; tolerance cannot excuse a different decision or tie-break. Utility values for unreachable candidates are not compared as ordinary numerical values.

`src.state_machine.verify_instance` is the benchmark reference implementation. A packed reference that does not reconstruct every AST can only stand in for it subject to explicit, independent differential evidence for public predicates, V4, per-cell role costs, normalization, and V5, including adversarial thresholds. Its current reduced-domain agreement is useful but does not independently prove all 1,394,064 records. Full comparison with that packed reference must be reported as such; it must not be presented as complete direct AST-reference validation. Compact-key guard decoding used for labels should be implemented independently of the FAST label code, and a separate small-AST suite must check both against `semantic_key` and `mechanism_labels`.

Until the FAST implementation, four complete family comparisons, runner fingerprint validation and measured runtime gate all satisfy the preregistered requirements, this protocol is not a claim that FAST and REFERENCE are equivalent.
