# PAPER CONTRIBUTION CLAIMS V1 · DRAFT

## 可写入当前论文稿的主张

> 在有限、能力约束的通信意图合同 DSL 中，状态—时间—资源语义抽象与安全规范化支持无图的按需搜索。该搜索按冻结的公开分数和规范语义键产生具有精确排序证书的结构合同流。固定开发面板中，与同域强通用 best-first 程序合成相比，当前方法减少了共同认证查询的在线搜索成本，并在所测资源限制内取得更高的 Depth 3 认证覆盖。

数学保证的对象是指定公开谓词、能力、六单元状态机、操作符与参数范围，以及证书能覆盖的有序前缀。领域方法包含合同上下文同余、能力下界、状态／时间转移、语义归一化及词典序代表恢复。Best-first、抽象解释和语义去重各有通用先例。本文的贡献落在合同专用抽象如何在合法空间上缩减搜索。 [既有技术归因与证明范围](PAPER_CONTRIBUTION_BOUNDARIES.md)

## 可报告的开发证据

- 原深度 92 个共同认证查询的耗时 median/p95 为 0.213/0.382 秒对 0.586/5.054 秒，当前方法与通用基线分别完成 96/96 与 92/96。这组条件化耗时和全分母覆盖应成对出现。
- Depth 3 的 K=500 开发覆盖为 24/24 对 5/24。当前方法取得 19 个全长和 5 个短域证书，通用基线的五个证书均为短域，其余 19 个在前沿限额下停止。该面板仅包含 high-conflict。原历史 `DEPTH3_PARTIAL` 判定继续保留。
- 合同专用下界、精细包络和搜索期规范化的单因素开发对照增加了展开数和耗时。A6 包含规范化改变提前归并机会的边际作用。开发数据不能确立面向独立样本的统计优势。 [开发集证据](PAPER_DEVELOPMENT_COMPARISON.md)

## 宣称边界

| 可陈述 | 仍缺证据或超出范围 |
|---|---|
| 合同抽象、正则表示和精确前沿在冻结的有限 DSL 中组成一种可核验的搜索方法。 | A*／best-first、抽象解释或语义去重的首创性，以及超出已证明语义范围的适用性。 |
| 既有合同流输入相同时，已达到的协议轨迹、代表和效用字段保持一致。 | 相同合同流下达成率提高，或 Depth 3 必然提高协议率。 |
| `benchmark_verified` 指冻结抽象状态机中的验证结果。 | 真实网络履约与部署证明。 |
| 已有可用图时，合同索引在原深度的 96 个暖态查询合计耗时更低。完整图缺失或现有图的能力覆盖失配时，在方法支持的 DSL／能力范围内可以直接从语法和公开能力搜索。 | 无图方法在所有场景下优于合同索引的在线速度。图缺失条件下的直接启动是适用性，速度仍需单独量度。 [成本审计](PAPER_COST_FAIRNESS_AUDIT.md) |
