# External semantic reference audit

`python -m tools.audit_external_reference --output-dir <new-directory> --profiles 27 --depth 2` builds an independent full syntactic AST stream, converts every AST to a lossless compact signature, sorts/deduplicates fixed-size chunks, merges runs, separately serializes the DP semantic keys, and compares both sorted streams byte-for-byte. It checks the syntax count against a separate recurrence. Hashes are never the equality test. It accepts only synthetic public fixtures and does not generate any experimental seed or acceptance outcome. It refuses existing output paths. Source, configuration, and interpreter/dependency fingerprints are captured at the beginning and end; a change invalidates the audit.

`CompactEncoder` packs a semantic signature relative to a fixed public registry and profile domain. Its validity depends on injectivity of the packing for that public context and consistency with `semantic_key`; it cannot prove the underlying semantic signature is a congruence in every context. Independent tests and `SEMANTIC_EQUIVALENCE.md` must establish those conditions. Files are gzip-compressed newline records; bounded chunk size controls record count rather than exact memory. Sorted merge avoids retaining all reference ASTs in memory, but the DP implementation may itself require substantial memory.

## Complete 27-profile depth-2 external comparison

The cached independent AST-interpreter stream evaluated all **4,909,437** typed syntax ASTs from the synthetic public fixture and emitted **1,394,064** distinct compact semantic signatures. The graph library contained **1,394,064** keys. Full sorted signature streams compared byte-for-byte equal, with no hash-only matching. Wall time, including the four-worker external merges and comparison, was **811.879 seconds** under concurrent engineering load. The report is `results/engineering/external_full_depth2_cached_01/report.json` and records source/config/dependency, cache-wrapper and graph fingerprints, all unchanged during the run.

The accelerated interpreter caches exact original public-only function calls for a fixed public fixture. Before the full run it was checked against unmodified interpretation over the full two-profile depth-two grammar, full 27-profile depth-one grammar and the first 10,000 full-domain depth-two ASTs. Those checks do not constitute an independent proof for all cache behavior. The full comparison is scoped to this specific public grammar and implementation snapshot, not to arbitrary grammars or real networks. No SMOKE, PILOT or CONFIRM seed was used.
