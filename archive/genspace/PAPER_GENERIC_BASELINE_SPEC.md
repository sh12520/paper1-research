# GENERIC_ABSTRACT_BEST_FIRST

This is a same-domain implementation of abstract-interpretation-guided optimal synthesis. It follows the general pattern of representing sets of completions as typed partial programs, splitting a hole's finite domain, and ordering an open frontier by admissible objective bounds. It adapts minimization to an exact ranked stream over semantic classes. Mell, Zdancewic and Bastani's POPL 2024 formulation motivates this design. The adaptation does not reproduce their complete system or their two DSL instantiations. [Optimal Program Synthesis via Abstract Interpretation](https://www.cis.upenn.edu/~stevez/papers/MZB24.pdf)

## Same-domain comparison

Every applicable method receives the same serialized query, effective depth, finite public grammar, available capability roles and packed semantic identity. The depth≤2 structural stream allows one or two mechanism groups. Depth 3 allows one through four. The static B2 stage is separate and unchanged. The search does not prune contracts based on physical feasibility or mutual acceptance. Those checks run downstream in the shared verifier and bilateral protocol. Search uses public data only, with no complete graph or availability/semantic index. [Implementation](results/paper_method_dev/generic_search.py) · [Frozen rank rules](GRAMMAR_BOUND_SPEC.md)

## Search and bound

1. Begin with one typed Clause hole. Apply the shared public abstract transfer to each queued partial program. Reuse repeated syntactic subtrees through the shared bounded abstract evaluation cache. Constructor productions are restricted by the same availability and depth. A group interval can reject a subtree only when it is disjoint from the eligible group interval.
2. Refine the hole with the smallest grammar cardinality, breaking ties by its stable path. For a Clause hole, the cardinality is the finite number of syntax trees at that depth under the available grammar. For a profile hole it is the number of allowed public tuples. Larger profile domains are partitioned by a public scalar coordinate chosen to minimize the largest bucket, followed by number of buckets and a fixed coordinate order. Small domains are enumerated directly. Each refinement is a disjoint and exhaustive partition. A fixed-preorder option is retained as a diagnostic with the same bound and proof.
3. Compute both a monotone interval endpoint bound and a finite product relaxation. The interval calculation independently bounds violation, margin, quality, cost and group count, evaluates in the same order as the exact FLAT arithmetic, and uses sign-adjusted extrema. The product calculation keeps demand, margin and quality from the same local output alternative. It minimizes each relaxed position over represented public profile/level values or idle, includes a nonnegative cost lower bound conditional on activity, then adds the lower bound on the whole-contract group term. Bound evaluation memoizes repeated elementary factors. A queued child also inherits its parent's lower bound by restricting the completion set.
4. Resolve partial states by increasing bound, using insertion order only for frontier priority ties. Score each distinct eligible complete semantic signature once with the frozen exact score. Accumulate all derivations with the same key and retain the lexical minimum raw witness for it. Apply frozen normalization to that witness and re-encode it before emission. No contract-specific profile-position quotient or canonical symbolic template merging is used by this comparator.

### Soundness

Complete refinements partition every legal raw derivation. The public abstract transfer encloses the output projection of each derivation, including those where conditional normalization collapses branches. Local abstract alternatives contain the actual profile/level or idle result at every position. An active position always contains the static roles and the abstraction's mandatory roles. The minimum over supersets of this mask bounds the position's exact role cost. The score's positive cost term means that replacing the exact cost with this minimum is safe. Idle includes exactly zero executed capability cost. Independent choice of local alternatives and lower-bound group count relaxes any shared inputs across positions, so the product minimum over reals bounds every concrete score. The interval endpoint bound preserves inequalities directly in the prescribed sequence of finite rounded binary64 operations.

The product regrouping is rounded downward using the same magnitude scale as the frozen joint-bound proof. The additional per-position cost weight/division introduces fewer than 128 rounded operations across either evaluation tree. The absolute weighted inputs remain bounded by the frozen scale because the registry costs are nonnegative and the active cost estimate is no greater than the all-role cost. The accumulated rounding allowance bounds the error of both trees on the frozen public domain. Taking the maximum of the interval, corrected product, and parent bounds preserves admissibility. [Frozen binary64 bound analysis](GRAMMAR_BOUND_SPEC.md)

Every unresolved derivation is represented in the partial heap. The complete heap is ordered by exact score then unsigned compact semantic key. Only an empty partial heap or a **strictly greater** frontier lower bound permits emission. Equality must be expanded so another key or a lexically earlier derivation can still be discovered. A full request has K emissions; a short request certifies every eligible key only after both queues exhaust. An engineering cap leaves unfinished checkpoints uncertified and does not affect the validity of earlier emitted prefixes. A bound or witness contradiction fails closed.

The independent complete reduced-domain development replay compared 18,896 raw ASTs and 670 eligible semantic signatures across ten existing domain-by-depth cases. The entire stream, exact score bits, minimum raw witness, normalized witness and exhaustion agreed in every case. A focused descendant audit checked 1,128 frontier terms across both hole-selection strategies. The bound held for the 1,044 terms with eligible completions, and no group-domain rejection removed an eligible descendant. The proof covers the frozen rules; the reduced replay tests the implementation on those particular domains. ## Counters and fairness

The cursor interface and cutoff fields match the current graph-free search. Queue admissions include pending complete syntax leaves when their bounds are still in the frontier. Partial-node expansions count hole refinements. Raw AST materializations count completed derivations constructed before any terminal identity merge. Complete leaves examined, unique complete semantic signatures, scores, normalized witness reconstructions and terminal duplicates are separate counters. Peak frontier includes partial and complete heaps, and RSS uses the common host probe. No graph storage, build or load is charged to this method. Query-local transfer, factor preparation, memoization and witness recovery are online work. Exact-score counts and bound calls are distinguished from protocol-verifier calls. Structural capacity and private utilities never determine frontier order.
