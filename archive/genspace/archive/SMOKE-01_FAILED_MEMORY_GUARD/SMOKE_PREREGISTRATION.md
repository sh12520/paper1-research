# SMOKE-01 preregistration — execution diagnostics only

Status: prepared before generation of any official SMOKE-01 instance. This is a diagnostic run for implementation and computational checks, not the 20-seed pilot or confirmation set. It does not test gates A–E or compute bootstrap intervals. The only allowed instance namespace is `GENSPACE-FAIL-01-SMOKE`; no PILOT or CONFIRM seed is generated or read. Each of the 96 configurations receives seed indices `0` and `1`, for exactly 192 paired instances. Every method consumes one identical complete serialized instance and fixed registry/state; independent of these research preferences, O1 candidates are generated from public input only.

## Deterministic instance identity

The Cartesian configuration order is family `[F1,F2,F3,F4]`, resource_pressure `[low,medium,high]`, preference_conflict `[medium,high]`, capability_richness `[sparse,rich]`, composition_depth `[1,2]`, with the rightmost coordinate changing fastest; each configuration is followed by seed indices 0 then 1. An instance ID is `family__pressure__conflict__richness__d<depth>__s<seed_index>`; it contains only Windows-safe characters. The canonical numeric RNG seed is derived by the existing `derive_seed('GENSPACE-FAIL-01-SMOKE', family, configuration, seed_index)` using canonical JSON and SHA-256, with no output-dependent modification. Serialize one complete instance once before dispatch; preserve the full/public/private instance hashes, semantic graph and index manifest hashes, and execution snapshot. Reruns read the same serialized bytes, not regenerated values.

## Fixed audit artifacts and repeat subsets

Only four per-candidate audit NPZ files are produced: `F1`, `F2`, `F3`, `F4` each with `medium__high__rich__d2__s0`. Every method's first-failure or verified status is retained in these four artifacts. All other instances receive aggregate validator counts, not candidate-level NPZ output.

The **8-instance same-worker rerun subset** is the Cartesian product of family `[F1,F2,F3,F4]`, pressure `medium`, conflict `high`, richness `rich`, depth `2`, seed index `[0,1]`. These are fixed by coordinates, before any result exists. Their non-timing result fields, complete compiled action data, and instance hashes must compare exactly with their primary results; timing is recorded separately and excluded from equality.

The **16-instance worker-count comparison subset** is family `[F1,F2,F3,F4]` × pressure `[low,high]` × conflict `medium` × richness `sparse` × depth `[1,2]` × seed index `0`. These same serialized inputs are evaluated using one and two worker processes; all non-timing fields and hashes must match exactly. The two subsets are not adjusted after observing outputs. No extra main-grid instances, alternate seed indices or replacement fixtures are permitted.

## Diagnostics and invariants

For each method and instance record the namespace, ID, config, seed index, instance/public/private hashes, candidate and eligibility/rejection counts, acceptance, selected representative and compiled actions, utility values, Nash welfare, structural novelty, mechanism labels, and measured runtime. Summaries group by method, configuration and family and must include denominators. Summaries report raw agreement/deadlock counts and engineering timing only; per-instance utility and mechanism fields remain in raw results. No research gate, rate-based success criterion, significance, innovation or failure conclusion is computed.

The SMOKE status is PASS only if all 13 invariants pass: (1) 192/192 instances complete; (2) no crashes; (3) no silent skips; (4) all four methods share an instance hash; (5) semantic containment M0⊆MR⊆B2⊆MC; (6) exact O1==B2 semantic set under NO_STRUCTURAL_CAPABILITY; (7) invalid capacity/hard/capability/semantic candidates never verify; (8) no NaN/Inf; (9) all utilities in [0,1]; (10) complete output schemas; (11) fixed 8-rerun non-timing equality; (12) fixed 16 one-versus-two-worker non-timing equality; (13) execution snapshot unchanged. A failed or uncheckable invariant is SMOKE_FAIL, never silently treated as pass. V2–V5 invalidity and no-structural equality require exact public mask/set checks, not a tolerance on rate differences.

A two-worker main dispatch is permitted only when a conservative memory guard passes; if not, use one worker. The one-versus-two-worker invariant still requires an actual two-worker check: if that check cannot safely execute, the result cannot be reported as full PASS. Record load, memory guards, skipped resource configurations and all exceptions. Do not begin until the source, dedicated SMOKE snapshot, no-structural verifier, namespace guards, tests and this preregistration have been independently verified; the current document alone does not constitute completion of those checks.

Public eligibility is defined as capability-conditioned candidate count minus V1/V2/V3 first-failure counts; it does not imply physical feasibility or acceptance. Finite and unit-interval checks apply to defined row outputs and V5-reached utilities; undefined utilities for earlier-rejected candidates remain absent rather than zero. Timing median/p95/max uses linear interpolation at (n−1)×p. The memory guard reserves 1 GiB for the OS and budgets 1.4×760,000,000 bytes per worker; execution stops the active phase below 768 MiB available memory. Source, graph, all 17 index files and the dedicated SMOKE execution snapshot are checked before and after each instance, and plan/preregistration/serialized-instance hashes are checked again at completion.
