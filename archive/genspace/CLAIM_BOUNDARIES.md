# Claim boundaries

This project is a finite, discrete diagnostic experiment, not a new negotiation algorithm. The capability-composition oracle is an exhaustive existence benchmark, not a deployable proposed method. Its conclusions are conditional on the explicitly fixed grammar, registry, instance distribution, utility and resource model. A verified simulated action sequence is not evidence of execution on real network equipment. No LLM, ns-3, 5G-LENA, or TFH data is used. Pilots, if subsequently run, are exploratory and separate from untouched confirmation seeds.
