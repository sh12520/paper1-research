# Bounded semantic DP completeness argument

This argument is about the current finite, rich, fixed-public 3×2 benchmark grammar, not real networks or arbitrary role vocabularies. Grammar parameters are exactly the public finite domains; `Static` has depth zero; every configured profile and operator parameter is V1/V3 valid. The registry and predicates are the fixed documented implementation and all declared roles are present in rich mode. The compact transfer implementation and its complete independent cross-check are separate engineering obligations.

Let `T_d` be the set of all typed trees over that grammar of depth at most `d`, and `S_d={sig(t):t in T_d}`. Let `D_0={sig(Static(p)):p in P}`. Given a set of signatures `D_(d-1)`, define `D_d` as `D_(d-1)` union every unary constructor transfer on one member and every binary constructor transfer on ordered pairs of members, for each allowed public parameter. Each class must retain an available representative of depth at most `d-1`; a lexical winner alone is insufficient if it is deeper than another representative.

Assume the constructor-by-constructor context congruence in `SEMANTIC_CONGRUENCE.md`, and that each abstract transfer exactly implements that constructor on signatures. Then for all `d<=2`, **`D_d=S_d`**:

- Base: the only depth-zero trees are all `Static(p)`; the definitions coincide.
- Soundness: every member inserted at step `d` is a previous member or is the transfer of actual depth-at-most-`d-1` witness tree(s). Its signature is that of the resulting typed tree of depth at most `d`, so `D_d ⊆ S_d`.
- Completeness: take any tree `t` of depth at most `d`. If it is shallower, apply the induction hypothesis. Otherwise its root is one of the five unary/binary constructor forms and its children have depth at most `d-1`. By the induction hypothesis their signatures are in `D_(d-1)`; applying the same root and parameters to their retained representatives yields, by context congruence, exactly `sig(t)`. Hence `S_d ⊆ D_d`.

This is an induction about the specified mathematical DP, conditional on congruence and correct transfer. It is distinct from the outcome-equivalence lemma (equal signatures produce equal V2–V5 outcomes) and from implementation-level evidence. The graph implementation uses compact transfer, byte-exact signature encoding, and separate child-depth witness pool. Reduced-domain differential tests and the full depth-one test are evidence for its transfer. An independent full syntax-stream comparison is needed to certify that this implementation actually realizes `D_2`, and cannot be replaced by comparing counts alone.

The statement enumerates all syntactic signatures and **does not prune V2-invalid or V3-invalid children**. For this specific configured rich grammar, the fixed allowed profiles and parameters pass V3; the compact transfer rejects out-of-domain/invalid states instead of claiming support for arbitrary V1-typed trees. If future public domains include invalid children or alternate capability scopes, extend the representation and proof before using the compact enumerator; the scoped failure-monotonicity discussion in `SEMANTIC_CONGRUENCE.md` does not justify silently deleting semantic classes from `S_d`.
