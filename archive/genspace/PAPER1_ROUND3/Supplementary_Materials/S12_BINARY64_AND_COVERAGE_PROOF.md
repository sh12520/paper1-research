# S12 冻结公开评分的 binary64 运算与精确覆盖证明

本文档细化正文 §5.2–5.3。公式以冻结 3×2 单元和三种资源、原公开评分及角色模型为对象。源代码定位见末表。`S12_check_binary64_bounds.py` 可以单独运行，用标准库 `Fraction` 对照两个浮点求值路径的共同实数展开式并检查静态边界。脚本不载入任何实验实例，也不调用生产搜索器。边界检查是复现辅助，以下论证不依赖测试覆盖率。

## S12.1 共同叶值、运算范围和记号

`fl` 表示 IEEE 754 binary64、逐操作舍入到最近值且并列取偶。下文的 `+`、`−`、`×`、`÷` 在运算图中各指一次 `fl`，期望保留 Python 表达式的括号和顺序。概率、物理量和私有接受均不参与此证明。除非另注明，常数 0.025、0.02、0.08、0.01 指源代码读入后固定的 binary64 值，并作为两条实数展开式共有的精确叶常数。

1. 对每格及资源，先从已舍入需求值 `d`、有限非负容量 `c` 得到 `z=fl(fl(d−c)/max(c,1e−9))`。超限 `v=max(z,0)`，裕度 `m=max(−1,min(−z,1))`。这是两条比较路径的共同叶，比较和选取无额外舍入。`max` 的分母严格正。需求表由冻结公式计算，质量最高 0.8、速率最高 1.0，含空闲时各分量在 `[0,1]`；减法为非负量之间相减，即使 `c` 取最大有限数也不溢出。`z<0` 时 `|z|≤1`（舍入减法结果不低于 `−c`）；`z≥0` 时 `z≤fl(1/fl(1e−9))<2^30`。因此 `0≤v≤Z<2^30`、`|m|≤1`。`Z` 取已预计算的最大超限值。空闲选项超限为 0，纳入同一范围。实际开发采样容量远离极端值，本证明不依赖某一批次的容量极值。
2. 活跃格质量 `q∈[0,0.8]`，空闲为 0。掩码成本 `a` 取规范角色表的执行代价加三资源附加成本。12 个执行字段最高 0.02，附加资源仅有单一 EDGE 角色的 0.1，故所有存储后掩码成本满足 `0≤a<1`，全掩码的存储值 `Amax∈[0,1)`。语法结构组 `g` 是 0–4 的精确整数。在代码中 `cost_total` 与语义掩码表使用相同的排序角色与求和结果。RAN、FH 附加成本均为零，EDGE 附加成本表仅有 0 或 binary64 `0.1`，三分量聚合与逐项求和具有相同数值。计算成本叶值不计入后续重结合次数。
3. 精确评分与坐标界的六格按时间优先、状态次之，每格资源次序为 RAN、FH、EDGE。联合界使用同一预计算 `v,m,q`。选项掩码包含所有实际单元选项，且每个受评估格的选择非空。角色掩码的超集最小值由冻结表的精确浮点 `min` 取得。设 `W=32+32Z+12Amax` 为实数表达式，`32≤W<2^36`。完整和联合中未缩放的超限和至多 `18Z`、裕度和绝对值至多 18、质量与成本和各至多 6。所有其他精确中间量也因比例系数及上述范围而小于 `W`。考虑舍入传播后的这些量仍远低于溢出。裁剪、符号翻转、结构计数和掩码选择不计为舍入操作。

## S12.2 两条运算图

`fold(x)` 表示从 `+0` 依次逐项相加。完整评分为下表的图，不对运算做代数重排。对空闲格，`q=a=0`，可跳过相应累加，计数按全活跃格的上限。

| 图 | 顺序及节点 | 最多的 binary64 算术次数 |
|---|---|---:|
| 完整评分的聚合 | `SV=fold(v_00,…,v_52)`、`SM=fold(m_00,…,m_52)`、`SQ=fold(q_0,…,q_5)`、`SA=fold(a_0,…,a_5)` | 18 + 18 + 6 + 6 = 48 |
| 完整评分的归一化 | `V=SV/18`、`M=SM/18`、`Q=SQ/6`、`A=SA/6` | 4 |
| 完整评分的尾项 | `((((V−0.025×M)+0.02×A)+0.08×(1−Q))+0.01×g)` | 9 |
| **完整评分合计** | 从共同叶到 `f` | **61** |
| 联合路径的单格局部值 | `vl=((v0+v1)+v2)/18`（3），`ml=(0.025×((m0+m1)+m2))/18`（4），`ql=(0.08×q)/6`（2），`φ̂=(vl−ml)−ql`（2） | 11/格，6 格累计 66 |
| 联合路径的聚合 | `SJ=fold(φ̂_0,…,φ̂_5)`、`SA=fold(a_0,…,a_5)` | 6 + 6 = 12 |
| 联合路径的尾项 | `SJ+((0.02×(SA/6)+0.08)+0.01×g)` | 6 |
| **未校正联合路径合计** | 从选出的共同叶到 `Ĵ`（核对一个具体的六格选择，格内比较本身无舍入） | **84** |

注意局部 `ml` 先乘再除，完整路径先归一化后乘权。局部 `ql` 先乘再除，完整路径走 `0.08×(1−Q)`。实现先累加所有局部最小，再与括号内尾项单独相加。把查询内对所有备选的预计算数量计入整个搜索耗时，与证明所需的单条路径舍入次数是不同问题。图中没有依赖先前计算结果的乘乘项，只有与固定常数的乘除和线性组合。因此可将每个经过舍入的节点看作向下游传递的相对因子及附加误差。

## S12.3 可采纳性的数值证明

**坐标界。** 对固定正分母，浮点减除保序。裁剪后的超限保序，裁剪后的裕度反序。已舍入叶值之间的逐项关系经顺序累加仍成立。坐标路径先将更小超限和更大裕度代入 `V−0.025M`，再代入更小成本、更大质量及更小组数。乘正系数、减法的反序参数及顺序加法均符合相应方向。故坐标值直接不高于冻结浮点评分，无需余量。

**未校正联合路径。** 记 `J_h` 为使用某完成式 `h` 的实际六格选择、实际掩码成本和实际结构组执行上述联合图所得的浮点数。实际计算的 `Ĵ` 按格取浮点局部最小值，格内允许集合包含该完成式实际选择。同时成本和组数使用下界，联合图相应分量单调。故 `Ĵ≤J_h`。这一比较无需假定取最小前后实数分支的选择一致，也无需将浮点最小值视为已向下舍入。

令 `E(h)` 为将共同浮点叶和常数视为实数、对完整评分图精确运算所得值。联合图把相同的线性式重新分组，故去掉所有舍入后同样得 `E(h)`。对展开式，带系数求和的绝对叶量至多 `Z + 0.025… + 0.02… + 2×0.08… + 4×0.01… < Z+1`（小数带省略号表示前述 binary64 常数值）。`W` 至少为该值的 32 倍。对每个可精确加减乘除的操作真实结果 `y`，binary64 误差可写为 `fl(y)=y(1+δ)+ξ`，其中 `|δ|≤u=2^−53`、`|ξ|≤η=2^−1075`。正常数可取 `ξ=0`，次正规及零可取 `δ=0`。这覆盖取消误差，没有用最终接近零的结果做人为相对分母。

沿任一传递路径最多 128 个 `1+δ` 因子。与 1 的差不超过 `γ_128=128u/(1−128u)`。各加法子树不复制产生的 `ξ`，后续乘除常数的绝对缩放均不大于 1，因此一棵树的次正规绝对误差不大于 `128(1+u)^128η`。由三角不等式，完整评分浮点值 `f(h)` 与 `J_h` 的差绝对值不超过

```text
2 γ_128 W + 256 (1+u)^128 η.
```

上述表达式支配重结合误差；比较、裁剪与选取没有插入新的浮点舍入。对实际 `Ĵ`，局部值的绝对展开量和尾项也由 `Z+1` 控制，因此 `|Ĵ|≤W`，`Ĵ` 有限。

**余量与最后减法。** 实现计算 `δ̂=fl(2^−38 × fl(fl(32+fl(32×Z))+fl(12×Amax)))`。全括号由非负量求得，无取消；`32×Z` 作为二的幂的缩放无溢出，且可精确表示（包括正向缩放的次正规）。`12×Amax` 在冻结角色表中为正常数，括号内两次加法无下溢，最后的二幂缩放精确。即使按三次相对舍入估计，`δ̂≥2^−38(1−u)^3W≥2^−39W`，且 `δ̂<W`。最终 `fl(Ĵ−δ̂)` 在上述最近值、并列取偶模式下的上偏差至多 `u|Ĵ−δ̂|+η≤2uW+η`，因此

```text
fl(Ĵ−δ̂) ≤ J_h − δ̂ + 2uW + η
          ≤ f(h) + 2γ_128 W + 256(1+u)^128η − δ̂ + 2uW + η
          ≤ f(h).
```

最后一步用 `2γ_128+2u<2^−44`，而 `(256(1+u)^128+1)η/W < 2^−53`、`δ̂/W≥2^−39`。这说明安全性来自明确的校正量，最终减法无须强制向下舍入。计算模式要求普通 IEEE 754 binary64 舍入，保留图中乘、加、除的分立次序。对改变数值域、成本定义、`fast-math` 合并或改用其他硬件数值语义，需要重新证明。取有限 `max(L_coord,L_joint)` 后仍不大于任何完成式的公开分数。

## S12.4 搜索覆盖与截止证据

对一个公共查询，将所有合格原始类型推导作为根集合。构造器、参数和相关配置的等值分区穷尽其父域；已证明为空、缺能力或无结构机制的分支仅在相应条件成立时移除。不同推导可能映射到同一规范键，这并不破坏覆盖。合并模板必须共享固定语义字段与可见等值结构，并保留所有可补全的见证配方。赋值 trie 在每层以互异配置掩码覆盖下一变量的全部允许值。

查询时每个合法规范键均由可达的开放骨架、可达的开放赋值分区、已评分缓冲或已交付前缀覆盖。部分展开尚未装入全部孩子时保留该父结点下界，且此时不能生成完成的新检查点。设缓冲的最小对为 `(s*,k*)`。若未关闭区域的保守分数下界均严格大于 `s*`，则没有该区域产生的候选以更小分数、同分更小的规范键或同键更小的原始见证提前。已评分缓冲按 `(binary64 score, unsigned key bytes)` 排列；发现下界等于 `s*` 时保留并细化该开放区域。已交付前缀逐项归纳。短域还要求所有 open、in-flight 与 buffered 均为空。早先检查点已完成与当前目标达限未认证是不同状态。

独立 symbolic 裁判用 `RootCoverage.skeletons` 自根重建骨架分区，重新生成等值分区和模板见证配方，随后由 `RootCoverage.assign` 检查赋值 trie 的开放掩码和孩子掩码互斥且并集恰为允许集合。重算完成候选的规范键、见证、binary64 分数和截点；对开放节点要求 `threshold < claimed ≤ recomputed`。缓冲仍可有同分项，但 `(score,key)` 必须严格晚于截点。深度 3 另一个直接 typed-cover 格式使用自己的根到截点覆盖检查。两种裁判都读取归档断言以核对身份与内容，均不能靠原生状态字符串证明覆盖。裁判与生产者共享公共解释器、规范化、编码、抽象域和评分定义，因而仍有共同语义前提。独立性指覆盖验证和截止逻辑分离，以及重新计算判定证据。本节没有主张实现第二套独立通信解释器。
