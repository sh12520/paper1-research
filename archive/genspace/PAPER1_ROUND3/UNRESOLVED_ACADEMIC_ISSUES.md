# 正式投稿尚待补足的证据

当前稿件可提交导师审阅。M1–M6 已作正文和证据级处理，仍有以下投稿范围的证据缺口。

1. **独立确认**。两项主要终点均未运行，预注册通过条件均未评估。方法推广到未见查询的声明仍应等待正式授权、完整运行和独立复核。
2. **其他强合成架构**。已实现的同域抽象 best-first 是本研究的强通用基线。仍需要一类目标一致的独立架构作为投稿增证，例如对自底向上语义等价类枚举适配同一个 DSL、FLAT binary64、并列次序及证书口径。既有 A4 消融无法估计用另一套抽象转移替换现有精细包络的成本。
3. **实际通信外部效度**。F2 案例展示冻结基准中资源替代与双方接受的完整路径。实际 QoS、无线与前传队列、并发负载、跨域预留及网络履约仍缺独立证据。论文维持抽象基准的表述。
4. **独立审计交付成本**。S9 给出开发查询三段配对合计。单次连续服务链墙钟、部署时证书交付 SLO 以及同口径通用基线审计开销尚无测量。端到端运行结论需要补测。
5. **证明适用域**。当前未见冻结域内仍阻断导师审阅的明显数学缺口。更改数值求值模式、角色成本或 DSL 语义需要重新建立保序和余量条件。Depth 3 覆盖裁判与搜索共享冻结语义，未验证另一套独立的网络执行解释器。
