# Validator audit — ORACLE-RUNTIME-CLOSE-02

`src/state_machine.py` is the current finite benchmark validation path. It normalizes equal-branch `If` before V2 and costs, verifies public role descriptors and preconditions, compiles local time/state guarded behavior, and checks capacities and private acceptance. Setup cost is zero. Runtime costs use only the roles on the executed state/time path. Per-cell active role identities are retained in the signature because equal aggregate costs alone are insufficient under parent composition.

`SEMANTIC_EQUIVALENCE.md` proves equal signatures imply the same V2–V5 outcome for the same well-formed public instance and every admissible private preference, subject to the documented V1/depth and early-rejection conditions. `benchmark_verified` means only that this abstract state machine's constraints passed; it is not proof of real-network machine execution.

The semantic equivalence result by itself is not a proof that the bottom-up DP enumerates every class or that the execution path meets its time budget. The full 27-profile depth-two reference comparison matched the compact library byte for byte under its recorded audit snapshot; see `EXTERNAL_REFERENCE_AUDIT.md`. The old `engine.py` verifier and canonical fixtures are historical unit scaffolding, not the current benchmark path.

The FAST execution path has since been compared candidate by candidate with benchmark references on four F1–F4 ENGINEERING fixtures with rich and sparse capabilities. At depth one, all 1,539 rich-graph classes per fixture were inspected against direct AST interpretation; generated-class membership and lexical witnesses were checked against capability-conditioned syntax. At depth two, all 1,394,064 graph classes per fixture were compared with the packed evaluator, without truncation. Generated membership, public eligibility, V2/V3 stage flags, V4 feasibility, per-agent utilities, acceptance, Nash product, semantic novelty and behavior-based mechanism labels had zero mismatches. Every utility and Nash value reaching V5 was bit-identical. The numeric report intentionally leaves conditioned lexical-witness validation pending; separate full conditioned syntax/reference reports for the actual 31/26/19 patterns and negative-control pattern 0, plus final-snapshot rechecks, found zero lexical mismatches and matched the applicable four selected results. Exact eligibility, capacity and acceptance decisions were required; the predeclared numerical tolerance was absolute 1e-12 with zero relative tolerance. The separately fingerprinted ±1 ULP reservation regression passed below, equal and above each agent's utility for one engineering candidate, with bit-identical values and identical decisions. See `DIFFERENTIAL_VALIDATION_REPORT.md`, `results/engineering/conditioned_final_differential_provenance_v2.json` and `results/engineering/fast_ulp_boundary.json`.

The full depth-two reference was **packed**, not a full per-AST execution comparison. The existing complete two-profile depth-two AST/packed differential is reduced-domain evidence, not an exhaustive 27-profile per-AST proof.
