# Method notes

The search consumes a public profile domain, available capabilities, public capacities, and frozen capability predicates. Contracts use typed static, conditional, sequential, delay, validity, and offload operators. A depth budget controls nested compositions.

A frontier node represents a partially applied public grammar or a remaining profile-assignment domain. Conservative state, time, and resource envelopes supply score lower bounds. The lazy cursor normalizes contract behavior, groups equivalent symbolic templates, and reconstructs a lexical witness for each packed semantic key. An entry can be emitted once its score is strictly lower than the minimum unresolved bound. Equal-score candidates are then ordered by their packed semantic keys. The public rank has no access to either party's private preferences.

The proof scope is the fixed six-cell interpreter, the enumerated profiles and operators, and the implemented public predicate basis. The reduced-domain tests compare the public order and binary64 scores using a syntax enumeration and the same scoring definition. End-to-end deployment, wider grammar coverage, and full-paper performance reproduction are separate evaluation tasks.
