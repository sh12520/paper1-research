# 图表目录

总览图覆盖 81 个配置、10 个种子、每组 75,330 个释放任务。趋势图每个点汇总该设置的 10 个种子，其余因素固定在负载率 0.7、坏状态窗 5%、空口速率跌幅 50% 和截止期 600 ms 中对应的参考值。曲线仅连接离散设置。图中无误差线，配对区间见 [paired_differences.csv](paired_differences.csv)。

| 图 | 观察与用途 |
| --- | --- |
| [按期交付档位](overall_grades.png) | 三个有兜底的方法总按期率重合。结构化策略的边缘占比最高，主档占比相对静态回退更低。 |
| [控制开销](overall_control.png) | 结构化策略的平均轮次和耗时低于重协商，高于静态回退。 |
| [负载率](slice_load.png) | 随共享负载上升，各方法效用下降。结构化方法的效用在低负载略高于静态回退，0.7 和 0.9 时略低。 |
| [坏状态窗](slice_loss.png) | 增加突发故障使效用下降。在 15% 设置下，结构化策略的效用高于两种有兜底的对照。 |
| [空口速率跌幅](slice_dip.png) | 控制字节随实际采用的协议分支而变。75% 跌幅时结构化策略比静态回退有更高的效用和额外开销。 |
| [截止期](slice_deadline_ms.png) | 在参考条件下，400 ms 时结构化策略的效用增益大于较宽松期限下的增益。 |
